# Experimento espacial com regressão logística

Este repositório contém um exemplo curto de treinamento de um modelo de regressão logística em Python. Usei quatro registros fictícios com tamanho e velocidade para praticar o ajuste do modelo.

O script treina o classificador, mas ainda não faz previsões nem avalia o resultado. Com tão poucos dados inventados, ele não serve para prever a queda de meteoros.

## Como executar

Requer Python e scikit-learn.

```bash
python -m pip install scikit-learn
python space.py
```

O script ajusta o modelo e termina sem exibir resultados.
